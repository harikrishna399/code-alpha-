# Financial Health Dashboard — Power BI Project

This folder contains a source-controlled Power BI Project (PBIP) with a TMDL semantic model and PBIR report definitions. Open `FinancialHealth.pbip` in a recent Power BI Desktop version.

## Open and finish
1. Clone the repository and open `FinancialHealth.pbip` in Power BI Desktop.
2. Review any compatibility warnings, refresh/apply changes if prompted, and validate calculations and report interactions.
3. Save as a native `.pbix` file with **File → Save As** only after Power BI Desktop successfully opens and validates the report.

Table data is embedded into Power Query M as Base64-encoded synthetic CSV to avoid machine-specific source paths. Human-readable CSV source files remain in this repository.

## Validation status
The project structure and JSON files were generated and local JSON syntax was checked before upload. This environment cannot run the Power BI Desktop engine; native report opening, refresh and PBIX export must be verified in Desktop. All data are synthetic and only for demonstration.
